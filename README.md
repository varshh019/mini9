# Expense Tracker & Management System

A full-stack web application built using Python, Flask, HTML, CSS, and SQLite that helps users efficiently manage and track their expenses. The application includes user authentication, expense management, email notifications, and data visualization features to provide a seamless financial tracking experience.

## Features

* User Registration and Secure Login Authentication
* Add, Edit, Update, and Delete Expense Records
* Daily, Monthly, and Yearly Expense Tracking
* Email Notification Integration
* Interactive Dashboard for Expense Management
* Responsive User Interface with Dynamic Templates
* CRUD Operations with Database Integration
* Secure Session Management
* Docker Support for Easy Deployment

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* SQLite
* Jinja2 Templates
* Docker
* SMTP Email Services
